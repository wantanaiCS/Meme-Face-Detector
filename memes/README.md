# 🖼️ Meme Image Repository

โฟลเดอร์นี้เก็บภาพ Meme ที่จะแสดงตามท่าทางของผู้ใช้

---

## 📂 โครงสร้างโฟลเดอร์

```
memes/
├── surprised/      # 😮 ประหลาดใจ
├── happy/          # 😂 ยิ้ม/ขำ
├── angry/          # 😠 โกรธ
├── sleepy/         # 😴 ง่วง/เบื่อ
├── thinking/       # 🤔 คิด/สงสัย
├── thumbs_up/      # 👍 ยกนิ้วโป้ง
├── peace/          # ✌️ V sign
└── neutral/        # 😐 เฉยๆ
```

---

## 🎨 รูปแบบไฟล์ที่รองรับ

- **PNG** (แนะนำ) — รองรับความโปร่งใส (alpha channel)
- **JPG/JPEG** — ใช้ได้ แต่ไม่มีพื้นหลังโปร่งใส
- **GIF** — ใช้ได้ แต่จะแสดงเฉพาะ frame แรก

---

## 📏 ขนาดภาพแนะนำ

- **ขนาดมาตรฐาน:** 300x300 ถึง 500x500 pixels
- **อัตราส่วน:** สี่เหลี่ยมจัตุรัส (1:1) แนะนำ แต่รองรับทุกอัตราส่วน
- **ขนาดไฟล์:** ไม่เกิน 1MB ต่อภาพ

---

## ➕ วิธีเพิ่ม Meme ใหม่

1. เลือกหมวดหมู่ที่เหมาะสม (surprised, happy, angry, ...)
2. วางไฟล์ภาพลงในโฟลเดอร์นั้น
3. ตั้งชื่อไฟล์ให้สื่อความหมาย (เช่น `pikachu_shocked.png`)
4. โปรแกรมจะโหลด Meme ใหม่อัตโนมัติ

**ตัวอย่าง:**
```
memes/
  surprised/
    ├── pikachu_shocked.png
    ├── mind_blown.png
    └── omg_cat.png       ← เพิ่มใหม่
```

## 🔍 หา Meme ได้ที่ไหน?

**แหล่งฟรี (ไม่มีลิขสิทธิ์):**
- [Unsplash](https://unsplash.com/) — ภาพฟรี
- [Pexels](https://pexels.com/) — ภาพและวิดีโอฟรี
- [Pixabay](https://pixabay.com/) — ภาพและกราฟิกฟรี

**แหล่ง Meme (เช็คลิขสิทธิ์ก่อนใช้):**
- [Know Your Meme](https://knowyourmeme.com/)
- [Imgflip](https://imgflip.com/)
- Google Images (filter: Creative Commons)

**สร้างเอง:**
- [Imgflip Meme Generator](https://imgflip.com/memegenerator)
- [Canva](https://www.canva.com/)

## ⚠️ ข้อควรระวัง

1. **ลิขสิทธิ์:** เช็คให้แน่ใจว่าภาพที่ใช้ไม่ละเมิดลิขสิทธิ์
2. **เนื้อหา:** หลีกเลี่ยงเนื้อหาที่ไม่เหมาะสม ก้าวร้าว หรือก่อความเกลียดชัง
3. **ขนาดไฟล์:** ภาพขนาดใหญ่เกินไปอาจทำให้โปรแกรมช้า
